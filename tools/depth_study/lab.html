What did the small model learn?

At a selected block, we saved the incoming feature vector and the change the original block made. A small student learned one correction per channel and eight shared directions. Each denoising step has its own coefficients. The photo test checks whether a locally accurate prediction still makes a faithful garment after every later block runs.

What is stored, and what is active?

The original editor contains eight dual-stream blocks and 24 single-stream blocks. A time schedule keeps the weights and bypasses particular visits. A structural checkpoint omits the selected dense tensors from its files. Three-bit quantization stores a coarser number in each selected projection and keeps its computations. Lossless storage preserves the numerical weights.

Can one photograph be reused for another outfit?

The VAE first encodes each input photograph. A memory cache can reuse that encoding when exactly the same person or product appears in the next request. All 32 transformer blocks still render the changed pair. A blue-shirt request primed the cache for three trials.

Does this measure real fit?

For the five test photos, an annotated mask extracts the garment reference and blanks its pixels on the person. The original photograph supplies a known answer. The studio examples show a genuinely different garment on the source person. Their true worn appearance and physical measurements are unavailable. Camera-image similarity measures change relative to the frozen editor.

How can I use a phone or Windows laptop?

This inspector opens directly in a browser. The measured renderer uses MLX on Apple Silicon. A second device can act as a browser client to a reachable Mac-hosted studio. Native generation on iPhone and Android requires a model port and on-device testing.
